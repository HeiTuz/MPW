# 리서치·팩트체크 — 축 사전

아래 축은 조사 과정을 순서대로 실행하라는 명령이 아니다. 요청에 맞는 축을 골라 답의 대상, 근거, 판정에 무엇을 담을지 정할 때 쓴다. 중간 보고는 사용자가 요구한 경우에만 작업 흐름에 넣는다.

### 허용 근거 범위

제공 자료 안에서만 답할지, 외부 검색도 허용할지 먼저 정한다. 자료에 없는 사실을 기억으로 채우지 말고, 자료만으로 결론을 낼 수 없으면 그 한계를 답에 밝힌다. 핵심 사실 주장마다 초안을 쓴 뒤 자료의 해당 대목을 대조하고, 근거가 없는 주장은 삭제하거나 삭제한 위치를 표시한다. 사용자가 원하지 않으면 대조 작업 자체를 답에 옮기지 않는다. 날짜가 판단을 바꿀 때만 확인된 기준일을 적는다.

## 팩트체크 축

### 판정 대상

대상 칸에는 원문의 사실 주장과 시점·지역·범위를 기록한다. 복합 문장은 따로 판정할 수 있는 주장으로 나누고, 해석이 갈리면 채택한 뜻을 적으며, 가치판단·예측·의견은 판정 대상에서 떼되 그 안의 사실 전제는 검증한다.

### 판정 가능성 확인 후 등급 선택

판정에 쓸 수 있는 자료가 갖춰진 주장에만 다섯 단계 중 하나를 준다. 맞는 주장은 `사실`, 일부만 맞는 주장은 `대체로 사실` 또는 `절반의 사실`로 구분한다. 틀린 쪽도 정도에 따라 `대체로 거짓`과 `거짓`을 나눠 쓴다. 핵심 자료를 확인하지 못했거나 자료끼리 맞서 결론을 낼 수 없다면 **판정 불가**로 남기고, 확인된 것과 추가로 필요한 자료를 밝힌다. 확인 실패를 중간 등급으로 처리하지 않는다.

### 증거 3분류

지지 (Supporting) / 반박 (Contradicting) / 판정불가 (Undeterminable). 증거별 분류와 최종 판정은 구별한다. 개별 증거가 판정불가여도 다른 충분한 증거가 있으면 판정할 수 있고, 전체 근거가 부족하면 최종 판정 불가 경로를 따른다.

발표 시점, 정의·측정 방법, 원자료 수치의 차이도 반박 근거인지 살핀다.

### 최신성 탐색 순서

최신성이 결론을 바꿀 때 최근의 공식·1차 자료부터 확인하고, 필요한 경우 이전 자료로 범위를 넓힌다. 고정된 날짜 구간을 모든 질문에 적용하지 않는다. 최신성은 새 근거를 찾는 순서이지 증거의 강도를 대신하지 않는다. 새 단일 연구와 앞선 종합 근거가 다르면 둘 다 제시한다. 빠르게 바뀌는 분야의 고유명은 검색 도구가 있으면 익숙한 이름이라도 사용자 표기 그대로 현재 상태를 확인한다.

### 지역 소스 우선 + 교차검증

사안 소재국·분야의 공식 소스(정부·학회·공식 발표)를 우선한다. 결론을 가르는 주장이나 상충이 있으면 제3자 독립 기관(국제기구·저널·검증 통계)으로 교차 검증하고, 단순 확인에는 불필요한 단계를 강제하지 않는다.

### 의도 추정 보류 + 출처 신뢰도

표절이나 사기 여부처럼 사람의 의도를 단정하는 판단은 뒷받침할 사실이 없으면 유보한다. 근거의 신뢰도를 높게 둘 자료는 공식 원문, 검증된 통계, 동료심사 후 게재된 연구와 체계적 문헌고찰이다. 정식 게재 전의 프리프린트와 학회 초록, 전문 매체의 보도와 업계 보고서는 중간으로 분류한다. 일반 매체의 기사와 개인 의견은 낮게 표시한다. 논문을 인용할 때는 출판 상태, 철회 또는 정정 기록과 연구 설계를 함께 확인한다.

### 자료 층위

1차(공식발표·원본) / 2차(분석·학술) / 3차(백과·요약). 1차 자료 우선은 [templates/model.md](templates/model.md) §리서치와 같은 원칙이다.

## 리서치 유형별 축

시장조사: 규모·성장률 / 경쟁 구도 / 고객 니즈 / 기회·위협
경쟁사: 제품·가격 / 시장위치 / 전략·움직임 / 강·약점
학술: 선행연구·문헌 / 방법론 / 발견(합의된 것과 논쟁 중인 것 구분) / 연구 공백

## 출력 형식 골격

**팩트체크**: 대상(확정한 주장·범위) → 판정(근거가 충분하면 5단, 아니면 판정 불가) → 근거(지지/반박/판정불가) → 맥락 → 결론 → 출처(신뢰도)

**리서치 보고서**: 요약(핵심 발견에 필요한 개수) → 배경 → 핵심 발견(축별) → 분석 → 결론·권고 → 한계 → 출처

예시는 `templates/model.md` §리서치 참고.

## 완료 기준

요청된 조사 범위에 해당하는 항목만 내부 점검한다. 이 목록을 답변에 붙이거나 단계별 승인 절차로 바꾸지 않는다.

- [ ] 필요한 축이 사전에 명시됐는가
- [ ] 결론을 가르는 출처의 신뢰도가 드러나는가
- [ ] 1차 자료 우선 원칙을 따랐는가
- [ ] 팩트체크라면 증거 3분류(지지/반박/판정불가)가 명확한가
- [ ] 결론을 가르는 주장마다 그 내용을 실제로 담은 출처가 붙었는가
- [ ] 검색·접근 실패를 미확인으로 표시해 부재 증거와 구분했는가

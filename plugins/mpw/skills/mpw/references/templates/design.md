# DESIGN 오버레이 — UI·페이지·컴포넌트

## DESIGN 오버레이

실행 모드의 코어 위에만 겹친다. 이미지 DESIGN 레인의 필수 요소는 [image/lanes.md](../image/lanes.md) §레인 게이트 카드가 정본이고, 이 절은 실행 모드 코어와의 결합 및 조건부 확장만 소유한다. **조건부 확장**: 시그니처·마이크로 인터랙션·기술 제약은 구현 결과를 바꿀 때만 둔다. 방향은 제품 맥락에서 하나를 가정으로 선언하고, 막연한 미사어 대신 표면·서체·간격·상호작용처럼 관찰 가능한 속성으로 쓴다. 기존 UI 수리는 결함을 한 문장으로 지목하고 최소 수정부터 수행한다.

채워진 예시 (198자 실측):

```text
## 디자인 방향
- 방향: raw terminal — 종이 같은 오프화이트와 잉크 블랙, 정보 밀도는 높고 계층은 분명하게.
- 시그니처: 가로 시간선이 섹션 구분을 맡는다.
- 하드 제약: 기존 프레임워크와 접근성 대비를 지킨다.

## 완료 기준
- 구현 전 시각 테제 3줄을 정하고 결과와 대조
- 데스크톱과 375px에서 긴 문자열의 넘침을 확인
```

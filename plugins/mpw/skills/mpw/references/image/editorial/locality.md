## 로컬리티 매트릭스

장소나 문화 단서가 결과를 가를 때만 관찰 가능한 스타일·공간·빛을 적는다. 국적에서 얼굴형·피부색·체형을 끌어내지 않는다. 사용자가 준 사람·브랜드·장소와 원본 보존은 [../compiler.md](../compiler.md) §제공된 피사체와 브랜드 보존. 아래 가상 설정은 새 장면을 만들 때의 선택지다.

| 축 | 채택 패턴 | 버리는 패턴 |
|---|---|---|
| 피사체 | 사용자·참조의 성인 인물, 제공된 나이대, 헤어 길이/질감, 입술 마감, 의상 소재·핏 | 국적 명사만 있는 미성년 암시, 실존 연예인 닮은꼴 |
| 피부·얼굴 | 모공이 읽히고 잔털이 보이며 입자는 약하다, 촉촉한 베이스, 번진 로즈 립, 빗은 눈썹, 부드러운 색면 | porcelain/pale/yellow처럼 국적에 피부를 묶는 말, 플라스틱 피부, 자격 없는 glass skin 과잉(자격화는 [concept-collision.md](concept-collision.md) §문화 앵커 자격) |
| 헤어·뷰티 | 짧은 웨이브 단발, 로우 번, 잔머리, 얇은 베이스 메이크업, 약한 홍조처럼 보이는 스타일 | "K-beauty처럼" 단독, 완벽한 대칭·무결점 피부 |
| 의상 | 사용자 지정 의류의 형태·원단·색과 필요한 세부를 보존 | 요청 없는 브랜드 교체, 제공된 로고 삭제, 옷의 구조 대신 신체만 강조 |
| 서울/한국 공간 | 성수 붉은 벽돌 창고 파사드, 한남·한강진 갤러리 거리와 쇼룸 유리 반사, 익선동 한옥 처마·목재 문틀, DDP 은회색 곡면과 패션위크 플래시, 젖은 골목의 전선·낮은 상가 셔터, 밤 편의점의 유리 외벽과 음료 냉장고에서 나오는 찬 백색 LED, 낡은 공중전화 부스 유리에 맺힌 가로등 반사, 고속도로 휴게소 매대처럼 구조·재료·빛으로 명시 (일상 공간 단서: 관측 2026-10, 출처 2건) | 유명 매장 간판, 관광 스테레오타입 나열, 읽히는 실재 로고 |
| 광고/잡지 톤 | 지면 여백, 곧은 스탠딩 균형, 카메라 직결 플래시, 클램셸 뷰티광, 창에서 들어오는 확산광, 무광 지 질감 | "프리미엄/고급/트렌디"처럼 판정 불가 형용사 |
| 리얼리티 | 손이 소매를 잡아 직물 주름이 생김, 발 접지 그림자, 머리카락 잔결, 배경 반사와 피사체 림 방향이 같음 | 손·발·배경 상호작용을 빼 놓고 품질 구호만 붙이기 |
| 필름/컬러 | 필름명 하나 이하 + 결과 세 부분: 피부, 그림자, 하이라이트. 예: Portra는 따뜻한 피부, 옅은 중간톤, 천천히 꺾이는 하이라이트 | 여러 스톡을 한 컷에 쌓기, 해상도·걸작 구호 |

## 판정

- "한국인 느낌" → 스타일을 가르는 단서만 구체화하고, 원본 외형을 새로 만들지 않는다. 축 개수를 채우지 않는다.
- "서울 감성" → 지역명보다 건물 재료·거리 폭·간판 처리·시간대 빛·필요한 색 관계를 쓴다. 간판은 "추상적 빛 덩어리, 읽히는 실재 상호 없음"처럼 장면의 원하는 상태로 쓴다.
- "인공물 티 빼기" → 피부 결, 접지 그림자, 직물 장력, 손-소품 접촉, 배경과 같은 그레인처럼 보이는 증거로 바꾼다.
- "필름톤" → 이름은 닻일 뿐이다. 한 컷에 emulation 하나, 피부/그림자/하이라이트/할레이션/그레인을 직접 적는다.
- 국적 명사와 피부색·얼굴형을 한 쌍으로 고정하지 않는다. 피부는 관찰(촉촉한 베이스, 볼의 혈색)로 쓴다.

# Grok Bot 비공개 MPW 스킬

Grok Bot의 **마켓플레이스 → 내 플러그인 → 비공개 스킬**에 저장하는 계정 공유 스킬이다. Grok Build CLI의 플러그인이나 이 저장소의 `install.mjs` 대상이 아니다. 아래 지침은 이 계정의 Grok Bot에 저장한 `mpw` 스킬을 재구성하기 위한 호스트 어댑터다. MPW 규칙 본문은 루트 `SKILL.md`와 필요한 `references/`에서 읽는다.

- 이름: `mpw`
- 설명: `프롬프트 작성·검토·부분 수정·대상 도구 적응에 사용. 원문과 정확 문구를 보존한다.`
- 정본: `https://github.com/HeiTuz/MPW`, 검증한 커밋 `a3c76af112357d1b62f0287a345a5ce0aabee65d` (v2.33.5)
- Grok Bot 컴퓨터의 읽기용 체크아웃: `/home/box/agent-data/vendor/MPW`

## 지침

```markdown
# MPW (Grok Bot 비공개)

정본: https://github.com/HeiTuz/MPW
고정 커밋: `a3c76af112357d1b62f0287a345a5ce0aabee65d` (v2.33.5)
벤더(읽기 전용): `/home/box/agent-data/vendor/MPW`

## 언제
- 프롬프트를 새로 쓰거나 검토·퇴고·부분 수정할 때
- 대상 모델·도구에 맞게 문안을 적응시킬 때
- `/mpw`, 「프롬프트 만들어줘/검토해줘/다듬어줘」, 기준 원문에 지정한 축만 반영하는 요청

코드 구현·이미지/영상 실제 생성·문서 제작만 요청된 경우에는 해당 실행 경로를 쓴다.

## 절차
1. 위 벤더 디렉터리의 `SKILL.md`를 읽고 그 지시를 따른다. 이 파일의 짧은 안내를 MPW 규칙 본문의 대체물로 취급하지 않는다.
2. 정본 SKILL.md의 「필요한 자료만 읽는다」 표에 따라 이번 요청에 해당하는 `references/`만 읽는다.
3. 후속·부분 수정이면 지정 축만 바꾸고 나머지 원문·헤딩·순서·정확 문구를 보존한 통합 전문을 낸다.
4. 파일·셸·웹·앱 조작은 현재 Grok Bot에 실제 제공된 도구와 권한으로만 수행한다. 사용자 Mac 경로가 Grok Bot 컴퓨터에서도 접근 가능하다고 가정하지 않는다. 정본의 다른 호스트 도구 이름을 그대로 Grok Bot 도구로 주장하지 않는다.
5. 문안 작성만 요청받으면 완성 프롬프트에서 멈춘다. 별도 실행·게시·설치·푸시는 사용자 요청과 실제 권한이 있을 때만 수행한다.
6. 납품 형식과 출력 전 검수는 정본 SKILL.md를 따른다. 부분 수정에서는 정확 문구를 원문과 문자 단위로 대조한다.

벤더 HEAD가 고정 커밋과 다르거나 진입 파일을 읽을 수 없으면 그 사실을 알리고 다른 버전의 규칙을 적용했다고 주장하지 않는다.
```

## 재설치·검증

Grok Bot 컴퓨터에 공개 정본을 위 경로로 받아 고정 커밋을 체크아웃한다. 기존 파일이 있으면 출처와 변경 상태를 먼저 확인해 사용자 변경을 보존한다. 스킬을 저장한 뒤 앱의 **비공개 스킬** 목록에서 이름·설명·지침을 다시 읽고, 작성기에서 `/mpw`가 뜨는지 확인한다. 원문 보존 부분 수정 사례를 한 번 실행해 결과를 대조한다. 이 체크아웃은 고정본이므로 정본 갱신 시 커밋과 스킬 지침을 함께 갱신하고 다시 시험한다.

2026-09-27에는 Grok Bot 앱의 비공개 스킬 목록·지침·`/mpw` 자동완성을 확인했고, Bot이 부분 수정 시험 통과를 보고했다. 마켓플레이스 공개 게시나 플러그인 등록은 하지 않았다.

# Grok Imagine (xAI) — IMAGE 컴파일 레인

요청 신호가 `Grok` / `그록` / `xAI` / `Grok Imagine`이면 이 레인을 쓴다. 실행·OAuth·exact-N 큐는 설치가 공급하는 실행 어댑터 소관이며, 없으면 사용자가 선택한 도구에서 직접 처리한다. 여기 소관은 **붙여넣기 프롬프트 문법**만이다.

## 게이트 카드

| 항목 | 규칙 |
|---|---|
| 네거티브 | 긍정형 재서술. MJ/SD 스타일 `--no` 스택 금지 |
| 비율 | 본문에 `--ar` / 끝 `AR x:y` **넣지 않음**. UI·API `aspect_ratio`로 분리 (초상 기본 `3:4`, 전신 세로 `9:16`, 스퀘어 `1:1`) |
| 길이 | 상한은 [surfaces.md](surfaces.md) §0-1의 세 층(전달 채널·타깃 엔진·기계 계약) 중 가장 좁은 것이 준다 — 붙여넣기 배선에서는 유효 상한이 블록당 2000자로 떨어진다. 단일 초상·한 장면은 **600–1500자** 적정 (2026-07 실측) |
| 필수 | `Photo of…` / `Photoreal…` 오프너, 피사체 기하, 행동·공간 1장면, 조명 방향 1개, 렌즈/거리 character, 필름·그레인 등 매체 앵커 1개 |
| 금지 플래그 | Midjourney `--p` / `--stylize` / `--v` / `--sref` / `--seed`, SD weight `::`, 로컬 경로 참조 |

지원 AR(문서 기준, UI가 정본): `1:1`, `16:9`, `9:16`, `4:3`, `3:4`, `3:2`, `2:3`, `2:1`, `1:2`, 일부 Quality 모델에 `19.5:9`·`9:19.5`·`20:9`·`9:20`, `auto`.

## 본문 구조

한 문단 자연어(영문 권장). xAI Quality 예시 톤: 쉼표로 이어지는 관측 서술.

1. **오프너** — `Photo of a fictional …` (실존 인물 실명 복제 대신 가상 페르소나 + 관측 기하)
2. **피사체** — 나이대·체형 시각 비례·얼굴 기하를 가상 페르소나로 적는다. 실존 인물 닮은꼴은 이 레인의 소관이 아니다([editorial/tier2-safety.md](editorial/tier2-safety.md) 금지선, [from-image.md](from-image.md) 레퍼런스 인물 규칙)
3. **의상·수위 경계** — 화면에 보이는 옷/피부만. 성인 요청 시 장면으로 정의 (`lingerie-editorial, adult, no sex act` 등). 미성년 표현 금지
4. **공간·포즈·시선** — 한 컷 한 행동
5. **카메라** — 거리 m + mm character + DOF
6. **조명** — key 방향 1 + fill 성격
7. **그레이드** — 저채도/필름명/그레인; 사용자 팔레트 토큰이 선언돼 있으면 병기
8. **마감** — `photoreal`, `clean brand-free finish`

비율·Quality·해상도(1k/2k)는 본문 밖 **UI 노트 한 줄**로만.

## 타엔진에서 옮길 때

| 가져오지 말 것 | 대신 |
|---|---|
| 끝 `AR 3:4` | UI `aspect_ratio: 3:4` |
| `--p m…` personalization | 생략. 얼굴은 기하 코어 또는 이미지 참조 슬롯 |
| HEX 3–5 강제(gpt-image-2) | 색 이름·온도·필름 룩 문장 |
| Higgsfield 프리셋명 본문 삽입 | UI 프리셋 분리 |
| 긴 헤더형 Scene/Camera 라벨 블록 | 한 문단 산문 |

## 요청 분기

| 사용자 말 | 산출 |
|---|---|
| `그록용으로 다시` / `Grok Imagine 프롬프트` | 프롬프트 블록만 (실행 금지) |
| `Grok/그록/xAI로 생성` + 장수 | ImgGen2 explicit Grok OAuth 실행 레인 |
| NSFW·란제리·시어 패션 | 성인 가상 페르소나 + 화면 서술 (`lingerie-editorial, adult, no explicit genitals, no sex act`) |

## 출력 형식

- 복사 블록 1개 = 1컷
- 변형 컷은 별 블록 (의상/포즈/배경 중 **한 축만** 변경)
- `길이: N자`는 실측만
- 실행 요청이 없으면 프롬프트만 반환

## 함정

- Grok용인데 MJ 플래그를 본문에 남기면 무시되거나 노이즈.
- “xAI 느낌”만으로는 제공자 라우트가 아님 — 미학과 `Grok으로 생성` 실행 의도를 혼동하지 않는다.
- 실명에 기대 인물을 지정하면 드리프트·정책 흔들림이 크다. 피사체는 관측 가능한 기하로 적고, 실존 인물 닮은꼴 요청 자체는 위 금지선으로 돌린다.
- 본문 끝 `AR 3:4` 금지 — UI `aspect_ratio`만.
- 프롬프트 재작성 요청에 ImgGen2/`image_generate`를 끼워 넣지 말 것.

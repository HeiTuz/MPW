# 텍스트와 구조가 있는 이미지

이미지 안의 글자, 배치, 연결을 실제 결과에서 확인하기 위한 작성 기준이다. 단순한 이미지에는 필요한 한두 조건만 남긴다. 입력 표면의 길이, 비율, 해상도와 품질 설정은 [surfaces.md](surfaces.md)와 [surface-contracts.md](surface-contracts.md)가 정한다. 아래 항목은 고정된 포스터 형식이나 색상 프리셋이 아니다.

정확 카피는 §이미지 안의 글자·§산출물별 고정 요소·§점검부터 읽는다. 글자 자체가 주제이면 §글자와 이미지의 관계·§판독 대상과 반복 텍스처를 더하고, 시리즈가 아니면 §시리즈·덱 일관성은 생략한다. 홍보물의 구조까지 설계할 때만 전체 판단 축을 확인한다.

## 먼저 가를 것

정확한 **글자**, 요소 사이의 **구조와 연결**, 글자와 이미지가 닿는 **물리 관계**, 여러 컷의 **일관성** 중 무엇이 실패하면 목적이 무너지는지 고른다. 한 컷의 제목 철자가 핵심이면 먼저 그 글자를 잠그고, 과정도라면 연결과 순서를 먼저 적는다. 광고 사진에 글자 하나를 얹는 일과 글자 자체를 물체처럼 다루는 일은 다르다. 지배적인 축만 필수 조건으로 올리며 다른 축을 모두 기입하는 양식은 만들지 않는다. 표면이 이미 받는 설정은 이미지 본문에 다시 쓰지 않는다.

## 산출물별 고정 요소

아래 행은 해당 산출물을 요청받았을 때 빠뜨리면 모델이 추론하기 어려운 정보다. 사용자에게 없는 내용은 질문이 꼭 필요한지 먼저 판단하고, 창작 재량으로 정한 부분을 사용자 사양이라고 쓰지 않는다.

| 산출물 | 모델이 추론 못 하니 반드시 적을 것 | 흔한 실패 | 요청 없으면 넣지 않을 것 |
|---|---|---|---|
| 정보카드·썸네일 | 실제 제목과 정보의 우선순위, 읽는 순서, 대상 독자 | 장식이 숫자나 핵심 안내를 가림 | 포스터식 효과와 임의의 통계 |
| 도해·플로·차트 | 실제 데이터, 노드의 역할, 연결의 출발과 도착, 축과 단위 | 화살표 방향이나 범례가 틀림 | 근거 없는 수치와 관계 |
| 제품 설명 도해 | 제공된 제품의 부위, 설명할 기능, 부위와 라벨을 잇는 선 | 다른 부위에 설명이 연결됨 | 새 기능과 가짜 인증 표시 |
| 만화 페이지 | 패널별 사건과 순서, 인물과 말풍선의 대응 | 장면 순서나 발화자가 뒤바뀜 | 독립 결과물을 한 페이지에 합침 |
| 슬라이드 컷 | 해당 장의 주장과 증거, 제목과 본문의 위계, 필요한 도표 | 읽을 수 없는 범례나 서로 다른 장의 내용 혼합 | 지정되지 않은 덱 비율과 장식 통계 |
| 아이콘 | 알아볼 대상과 구별할 형태, 배경이 필요하면 그 조건 | 작은 크기에서 대상이 구분되지 않음 | 입체 질감과 촬영 조명 |
| 브랜드 목업 | 제공된 상표의 적용 위치, 제품 또는 매체의 형상, 보존할 색 | 로고가 변형되거나 존재하지 않는 문구가 생김 | 새 브랜드 자산과 임의의 색 코드 |
| 키아트·표지 | 제목과 주체의 위계, 작품을 드러낼 장면 관계, 필요한 경우 후속 조판 공간 | 분위기만 있고 제목을 놓을 자리가 없음 | 요청하지 않은 출연진·크레딧 |
| 디자인 홍보 포스터 | 관객에게 남길 인상과 정확한 행사 정보, 글자와 장면의 주도권 | 안내 카드로만 축소되거나 정보가 배경에 묻힘 | 정보카드식 균등 칸 나누기 |
| 글자 주제 포스터 | 읽어야 할 글자와 글자가 점유하는 공간, 변형 뒤에도 알아볼 형태 | 재료 표현이 획을 끊어 글자를 못 읽음 | 임의의 문구, 재질 묶음, 장식 수량 |

## 이미지 안의 글자

사용자가 준 문구는 철자, 공백과 문장부호까지 보존한다. 렌더할 문구를 따옴표로 한 번만 싣고, 여러 문구라면 제목, 부제, 제품명처럼 역할과 위치를 구별한다. 인용된 `NO FEAR`나 `4K`는 그대로 보일 카피이지 모델 실행 지시가 아니다. 설명용 카피를 추가했다면 사용자 지정 문장과 분리한다. 다른 언어로 바꾸거나 정보량을 줄여야 하는 경우에는 원문을 임의로 번역 또는 축약하지 않는다.

글자가 놓일 자리는 주변 물체, 사진의 시선 방향, 다른 글자와의 간격으로 설명한다. 제목 뒤에 필요한 대비와 여백을 남기되 획을 지우는 장식이나 이미지 요소가 그 공간을 덮지 않게 한다. 작은 문구가 틀리면 사용자 카피는 그대로 두고 표기를 더 또렷하게 하며, 실제 표면이 허용하는 해상도와 품질 단계, 글자 크기와 배치를 순서대로 검토한다. 이 조정으로 해결되지 않으면 해당 편집 기능이나 텍스트에 맞는 모델을 검토한다. 설정값과 단계의 권한은 [surface-contracts.md](surface-contracts.md) §4에 있다. 한글을 글자 사이 하이픈으로 분해해 정확도를 고치려 하지 않는다.

문자 레이어가 실제로 필요하면 배경 생성 뒤 별도 조판을 명시한다([compiler.md](compiler.md) §후속 조판 경계). 생성 이미지의 렌더 글자와 합성한 글자를 같은 납품물이라고 속이지 않는다. 결과를 볼 수 있다면 글자의 철자, 횟수, 행 순서와 의도하지 않은 작은 글자까지 확인한다.

## 글자와 이미지의 관계

먼저 앞에 보이는 평면이 글자인지 피사체인지 고른다. 무엇이 무엇을 가리고, 어디에서 잘리고, 어느 형태가 다른 형태를 담는지 결과로 쓴다. 인상으로 기억될 홍보물이라면 이 관계를 먼저 세우고 안내 정보를 필요한 자리에만 둔다. 읽는 정보가 중심인 카드라면 글자 위계를 먼저 지킨다. 하나의 관계를 선택했는데도 각 요소가 서로 다른 깊이를 요구하면 충돌을 풀고 나서 쓴다.

예를 들어 책 표지의 큰 제목이 뒤편 사진 일부를 가리고, 사진 속 손만 제목의 앞에 놓이도록 할 수 있다. 제목의 각 획은 손이 닿지 않는 나머지 영역에서 이어져 읽혀야 한다.

매장 유리의 글자는 유리 표면에 붙고 실내 조명은 그 뒤에서 보이게 할 수 있다. 글자까지 실내의 물체처럼 입체화하지 않고 반사만 유리 위를 지나가게 한다.

철도 안내 포스터에서 선로의 방향이 제목 줄을 따라 시선을 이끌게 할 수 있다. 선로가 글자의 빈 공간을 지나가더라도 획의 연결과 단어 간격이 끊어지지 않아야 한다.

재료가 글자의 모양을 크게 바꿀 때는 질감의 이름보다 판독 가능한 결과를 먼저 적는다. 표면이 녹거나 찢기거나 여러 면에 분할돼도 핵심 획이 이어져 읽히는지 확인한다. 특정 문장을 되풀이하는 방식이나 재질별 고정 문구 목록은 두지 않는다. 색 지시는 사용자 지정과 실제 색 입력의 권한에 맞추며 [surface-contracts.md](surface-contracts.md) §4.1을 따른다.

## 판독 대상과 반복 텍스처

반복되는 글자 모양이 모두 읽혀야 하는 것은 아니다. **판독 대상**은 실제 문구와 읽는 순서를 고정한다. **비판독 반복 텍스처**는 개별 기호를 정보로 읽을 수 없게 다루되 핵심 문구와 혼동되지 않게 한다. **판독 반복 진열**은 같은 정확 문구가 여러 물체에 실제로 반복되는 결과다. 이때 몇 군데에 보여야 하는지와 각각의 위치를 사용자의 의도대로 적는다.

같은 문구를 무심코 프롬프트에 두 번 쓴 것과 실제 반복 진열은 구별한다. 진열이 목적이라면 결과에 반복을 명시하고 각 항목의 카피를 바꾸지 않는다. 무늬가 목적이면 임의의 읽을 만한 안내문이 생기지 않는지 확인한다. 텍스처를 제거하려고 실제 필요한 표지판까지 없애지 않는다.

## 시리즈·덱 일관성

여러 장을 낼 때는 매 장의 목적과 변하는 축을 먼저 정한다. 공통으로 남길 것은 사용자 지정 문구의 표기 방식, 시각적 위계, 제공된 브랜드 자산, 실제 공유할 색 역할처럼 결과를 이어 주는 요소다. 공통 블록은 한 번 정의하되 각 장의 독립 실행에 필요한 조건은 그 장에도 전달한다. 슬라이드 컷은 각 장의 주장과 자료가 달라질 수 있으므로 화면 비율이나 그림 양식을 일괄 고정하지 않는다.

변주가 필요하면 무엇이 그대로이고 무엇만 바뀌는지 명시한다. 제목의 위치를 유지하면서 배경 장면만 달라지는 시리즈라면 새 장면 때문에 글자가 묻히지 않는지 확인한다. 색을 고정해야 하는 경우에도 사용자 색, 브랜드 입력 또는 창작으로 선택한 색 가운데 권한자를 하나만 둔다. 서로 다른 장마다 임의의 색 코드를 새 사양처럼 만들지 않는다. 제작 인계에서의 시리즈 운영은 [production.md](production.md) §시리즈 운영을 따른다.

## 무드·스타일 단어

무드나 사조 이름이 필요하다면 그 이름이 화면에서 만드는 차이를 한두 가지로 적는다. 예를 들어 차분한 장면은 낮은 대비와 넓은 빈 공간 중 실제 의도에 맞는 결과를 고른다. 이름만으로 팔레트, 렌즈와 소재가 한꺼번에 정해진다고 가정하지 않는다. 사용자 지정 매체와 상표는 보존한다. 느낌만 다른 새 시안이라고 하면서 기존 구조의 색 이름만 바꾸지 않는다.

## 점검

결과마다 먼저 핵심 글자와 숫자가 정확한지, 구조의 순서와 화살표가 맞는지, 글자와 이미지의 앞뒤가 일관적인지 살핀다. 그다음 반복이 정보인지 무늬인지, 원본 피사체와 브랜드가 보존됐는지, 시리즈 공통 요소와 컷별 차이가 요청대로인지 확인한다. 실제 이미지를 만들지 않았다면 이 항목은 문안의 검토 기준일 뿐 렌더 품질의 통과 증거가 아니다.

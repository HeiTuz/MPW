# 인물 이미지 브리프

우선순위: [../lanes.md](../lanes.md) §레인 게이트 카드 > [../compiler.md](../compiler.md) §원칙 > [../editorial-fashion.md](../editorial-fashion.md) > 이 파일. GPT Image 2.5·대상 미정 문안의 구획 형식과 판정은 [../surface-contracts.md](../surface-contracts.md) §3.2가, 원본 편집은 §3.3이 소유한다. 이 파일은 새 인물 이미지를 쓸 때 **무엇을 어떤 순서로 정하고, 참조 유무에 따라 무엇을 넣고 빼는지**만 다룬다. 어휘 사전은 [photo-results.md](photo-results.md)와 [scene-craft.md](scene-craft.md)에 있다.

공개 인물 프롬프트 모음 1,823건을 검수해 뽑은 작성 패턴이며 생성 품질 실측이 아니다. 원문 문장을 템플릿으로 복사하지 않는다.

## 인물 설정은 요청에서 온다

- 나이·성별·민족·국적·체형·얼굴형·헤어·메이크업·의상을 기본값으로 채우지 않는다. 현재 요청, 참조 이미지, 이어가는 작업의 확정 조건에 있는 값만 조건으로 쓴다.
- 외형이 정해지지 않았으면 장면이 요구하는 만큼만 쓴다: 성인인 한 사람, 역할·행동·표정. 셀피·뷰티처럼 외형이 결과를 가르면 목적에 맞는 선택을 하되, 요청마다 같은 나이대·민족·메이크업을 되풀이하지 않는다. 검수한 모음은 숫자 나이를 적은 항목이 모두 18–29세에 몰려 있었다. 이 편향을 기본값으로 옮기지 않는다.
- 숫자 나이는 사용자가 줬을 때만 쓴다. 성인임만 필요하면 `adult`로 충분하다. `girl`, 교복, 아이 같은 체형 묘사처럼 미성년으로 읽히는 표현은 요청에 있어도 성인 조건과 함께 명확히 한다.
- 국적·민족에서 피부색·얼굴형·체형을 끌어내지 않는다([locality.md](locality.md) §판정). 특정 피부색 미화어나 얼굴 비율 이상형을 기본으로 넣지 않는다.

## 참조 분기

참조가 **실제로 있는지**를 먼저 정한다. 한 프롬프트 안에 "참조가 있으면 유지, 없으면 익명" 같은 조건문을 두지 않는다. 검수한 모음에서 이 조건부 문구는 74건, 참조가 없다고 하면서 첨부 얼굴을 유지하라는 자기모순은 18건이었다. 재사용 템플릿을 요청받았을 때만 참조 입력 자리를 표시한다.

| 입력 | 쓸 것 | 넣지 않을 것 |
|---|---|---|
| 참조 없음 | 장면이 요구하는 인물 서술 | `reference`·`attached face`·`identity lock`·`100% unchanged` 등 보존 문구 전부 |
| 인물 참조 | 이미지 번호와 역할, 유지할 축(얼굴 특징·비율·피부톤·헤어라인 중 요청에 맞는 것), 새로 정할 축(표정·포즈·헤어 스타일링·의상 등) | 참조가 이미 전달하는 눈·코·입 형태의 재서술, 참조 외모와 충돌하는 형용사, 바꾸라고 한 축을 보존 목록에 넣는 것, 요청·참조 설명에 없는 성별 대명사(`the model`·`the person`으로 충분하다) |
| 제품·의상 참조 | 번호와 역할, 보존할 구조: 형태·실루엣, 색, 패턴 배치, 로고·라벨 위치, 봉제선, 여밈·하드웨어, 소재 | 참조와 다른 색·로고 문구의 재서술, 스타일 참조가 제품 형상까지 바꾸게 두는 것 |
| 인물 + 제품 | 두 역할을 번호로 나누고 각각의 보존 축을 쓴다. 권한 경계는 [../reference-authority-pitfalls.md](../reference-authority-pitfalls.md) | 한 참조의 조명·배경이 다른 참조의 정체성·제품 디테일을 덮게 두는 것 |
| 원본 사진 편집 | [../surface-contracts.md](../surface-contracts.md) §3.3의 변경·보존 구분 | 새 피부결·그레인, 인물 재서술 |

보존 문장은 참조 역할을 적는 구획이나 `CONSTRAINTS` 중 한 곳에 한 번 쓰고 다른 구획에서 되풀이하지 않는다. `CRITICAL` 같은 대문자 강조나 `100%` 반복은 조건을 늘리지 않는다. 동일성 보존은 결과를 보고 확인할 일이며 문구만으로 보장했다고 쓰지 않는다.

제품 참조가 있으면 로고·글자 제약을 "제품에 없는 로고·글자를 추가하지 않는다"로 좁힌다. 일괄 로고 금지는 참조 제품의 실제 로고·라벨과 충돌한다.

## 축별 작성 패턴

장면에 영향이 있는 축만 쓴다. 조건이 한두 개인 단순 요청은 한 문단으로 충분하다([../surface-contracts.md](../surface-contracts.md) §3.2 구조 선택).

| 축 | 쓰는 방식 | 흔한 과잉 |
|---|---|---|
| 구도·프레이밍 | 크롭 경계(`from mid-thigh up`), 피사체 위치, 머리 위·발끝 여백, 배경이 차지하는 몫. 비율은 요청했거나 실행 형식에 필요할 때만 쓴다 | 요청 없는 비율 추가, 비율을 본문·설정·첫 줄에 중복 |
| 카메라 | 눈높이 대비 카메라 높이 하나, 촬영 장치의 성격(전면 카메라, 손에 든 폰, 삼각대 위 스튜디오 카메라), 렌즈 성격의 결과(가장자리 늘어짐, 압축된 배경). 거리는 팔 길이처럼 장면이 정하거나 원근이 결과를 가를 때만 쓴다 | 이유 없는 거리·mm·조리개 수치, 장면과 무관한 기기 모델명·연도, `low eye-level`처럼 섞인 높이 |
| 조명 | 주광 하나의 방향과 성질, 그림자가 떨어지는 곳, 보조광·실용광, 배경 분리. 캐치라이트·반사가 같은 광원을 따르게 한다 | 성질 없는 광원 나열, `soft`와 강한 직광 플래시 동시 지정 |
| 포즈 | 체중이 실린 곳, 손이 닿거나 쥐는 대상과 쥐는 방식, 시선이 도착하는 곳, 어깨·턱 각도, 입 상태 | 감정 형용사만 쌓기 |
| 의상 | 종류 → 구조(칼라·여밈·소매·기장) → 소재와 빛 반응 → 착용 상태(주름·장력·늘어짐) | 같은 옷을 여러 구획에서 반복 |
| 색감 | 전체 그레이드 한 줄과 결과를 가르는 물체 색. HEX는 [../surface-contracts.md](../surface-contracts.md) §4.1 | 색 지정이 없는데 피부·머리·그림자까지 코드로 지정 |
| 피부·소재 질감 | 새 실사 생성에서 요청됐거나 과매끈을 막을 때 보정 정도를 결과로 한 문장(`light retouching that keeps pores and fine hairs`). 실패 처방은 [../realism.md](../realism.md) §1 | 원본 편집에 새 질감 추가, 피부 질감을 여러 구획에서 반복 |
| 오류 방지 | 장면에 실제로 있는 위험만: 폰을 쥔 손, 거울 반사 기하, 유리·플래시 반사, 겹친 손가락, 읽혀야 할 글자 | 해부학 오류·워터마크 등 일반 금지어 나열 |

## 장르별 골격

첫 줄에 용도와 촬영 방식을 한 문장으로 정하고, 조건이 몰리는 축에 구획 제목을 준다. 아래 제목은 예시이며 고정 양식이 아니다.

**스튜디오 인물.** 결정 축은 배경지와의 분리, 주광 방향과 그림자 대비, 크롭과 시선, 보정 정도다. `SHOT` → `SUBJECT`(요청 인물·표정·포즈) → `WARDROBE`(조건이 있을 때) → `LIGHT`(주광·보조광·배경지 색과 톤) → `CONSTRAINTS`. "스튜디오"라는 단어만으로 조명이 정해졌다고 보지 않는다.

**일상 셀피.** 먼저 촬영 방식을 하나로 정한다: 팔을 뻗은 전면 카메라, 거울 셀피, 다른 사람이 찍은 폰 스냅(셀피 아님). 전면 카메라면 폰은 프레임 밖에 있고 뻗은 팔·어깨 각도와 가까운 거리의 가장자리 늘어짐이 보인다. 거울 셀피면 반사 안에 폰의 뒷면과 쥔 손이 보이고, 시선은 거울 속 폰 쪽을 향한다. 폰이 얼굴을 가리려면 폰을 얼굴 높이로 올리고, 가슴 높이로 들면 얼굴이 드러난다. 플래시는 요청했거나 어두운 장면일 때만 쓰고, 쓰면 광점은 반사 속 폰 위치에 생긴다. 실내 빛은 실제 광원(창, 천장등, 스탠드, 폰 플래시)으로 쓰고 생활감은 요청에 맞는 소품 한두 개로 준다. 앱 보정·필터감은 요청됐을 때만 쓴다.

**패션 화보.** 의상이 주인공이다. 첫 줄에 캠페인·매거진·룩북 중 용도를 쓰고 `WARDROBE`를 가장 구체적으로 쓴다. 포즈는 실루엣·원단 움직임·디테일이 읽히는 동작으로 고른다. 로케이션과 빛은 옷의 소재와 색을 드러내는 쪽으로 정한다. 제품 참조가 있으면 보존할 구조를 `CONSTRAINTS`에 모은다. 룩북과 화보의 차이는 [photo-results.md](photo-results.md) §룩북 감도.

## 줄이거나 빼는 것

검수한 모음에서 반복된 형태다. 새 문안에 옮기지 않는다.

- 본문 앞의 `Model:`·`Resolution:` 같은 실행 설정과 품질 태그(`hyper-realistic`, `8K`, `ultra-detailed`). 실사 목표는 장면 조건으로 쓴다.
- 같은 사실(피부·헤어·팔레트)을 `SUBJECT`·`FACE`·`TEXTURE`·`PALETTE`에 나눠 반복하는 구획.
- 서로 부딪치는 지시: 참조 없음과 첨부 얼굴 유지, 림라이트 금지와 림라이트, 확산광과 강한 직광 플래시, 배경 전체 선명과 얕은 심도, 카메라를 의식하지 않음과 렌즈 응시, 블루아워와 한밤.
- 장면과 관계없는 카메라 제원과 긴 제외 목록. 제외는 짧은 자연어 제약으로 쓴다([../surface-contracts.md](../surface-contracts.md) §4).
- 앞 구획에서 이미 정한 조건(폰이 보이지 않음, 얼굴 유지)을 `CONSTRAINTS`에서 다시 쓰는 것.

## 검수

답변에 출력하지 않는 내부 확인이다.

- 요청하지 않은 나이·민족·체형·메이크업·의상을 사용자 조건처럼 넣지 않았는가
- 참조가 없으면 보존 문구가 없는가. 있으면 번호·역할·보존 축이 있고 참조 외모를 다시 묘사하지 않았는가
- 카메라 위치·광원·반사·손의 접촉이 서로 맞는가
- 크롭이 요청·참조 대상(얼굴, 제품)을 담는가. 손에 든 소품을 다른 자리에 또 놓지 않았는가
- 각 문장을 지웠을 때 결과가 달라지는가. 같으면 지운다

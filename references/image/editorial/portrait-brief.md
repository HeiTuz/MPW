# 인물 이미지 브리프

작성 규칙(층 모양·채우기·기본 인물·모델 아이덴티티)은 [../image-brief.md](../image-brief.md)가 정본이다. 이 파일은 참조 분기·장르 결정 축·검수만 다룬다. 우선순위는 [../lanes.md](../lanes.md) §레인 게이트 카드 > [../compiler.md](../compiler.md) §원칙 > [../editorial-fashion.md](../editorial-fashion.md) > 이 파일이며, 원본 편집은 [../surface-contracts.md](../surface-contracts.md) §3.3이 소유한다. 다른 엔진을 지정했으면 인물 설정·참조 분기·검수만 적용하고 형식과 참조 문법은 그 엔진 문서를 따른다.

공개 인물 프롬프트 모음 1,823건을 검수해 뽑은 작성 패턴이며 생성 품질 실측이 아니다. 원문 문장을 템플릿으로 복사하지 않는다.

인물 시리즈의 지정 축 비교나 프리셋 조합, 명시적 랜덤 요청에는 [portrait-variations.md](portrait-variations.md)를 읽는다.

인물 설정은 [../image-brief.md](../image-brief.md) §5.

## 참조 분기

참조가 **실제로 있는지**를 먼저 정한다. 한 프롬프트 안에 "참조가 있으면 유지, 없으면 익명" 같은 조건문을 두지 않는다. 검수한 모음에서 이 조건부 문구는 74건, 참조가 없다고 하면서 첨부 얼굴을 유지하라는 자기모순은 18건이었다. 재사용 템플릿을 요청받았을 때만 참조 입력 자리를 표시한다.

| 입력 | 쓸 것 | 넣지 않을 것 |
|---|---|---|
| 참조 없음 | 장면이 요구하는 인물 서술 | `reference`·`attached face`·`identity lock`·`100% unchanged` 등 보존 문구 전부 |
| 인물 참조 | 이미지 번호와 역할, 새로 쓰는 층(헤어·메이크업·표정·포즈·의상), 모델 아이덴티티면 [../image-brief.md](../image-brief.md) §5-2 | 얼굴형·눈코입·피부색·체형·나이 재서술 |
| 제품·의상 참조 | 번호와 역할, 보존할 구조: 형태·실루엣, 색, 패턴 배치, 로고·라벨 위치, 봉제선, 여밈·하드웨어, 소재 | 참조와 다른 색·로고 문구의 재서술, 스타일 참조가 제품 형상까지 바꾸게 두는 것 |
| 인물 + 제품 | 두 역할을 번호로 나누고 각각의 보존 축을 쓴다. 권한 경계는 [../reference-authority-pitfalls.md](../reference-authority-pitfalls.md) | 한 참조의 조명·배경이 다른 참조의 정체성·제품 디테일을 덮게 두는 것 |
| 원본 사진 편집 | [../surface-contracts.md](../surface-contracts.md) §3.3의 변경·보존 구분 | 새 피부결·그레인, 인물 재서술 |

참조 번호·역할과 보존 조건은 관계가 읽히는 곳에 한 번 쓴다. 참조 번호·역할은 첫 줄이나 Identity Reference에 한 번 쓴다. `CRITICAL` 같은 대문자 강조나 `100%` 반복은 조건을 늘리지 않는다. 동일성 보존은 결과를 보고 확인할 일이며 문구만으로 보장했다고 쓰지 않는다.

제품 참조가 있으면 로고·글자 제약을 "제품에 없는 로고·글자를 추가하지 않는다"로 좁힌다. 일괄 로고 금지는 참조 제품의 실제 로고·라벨과 충돌한다.

## 장르별 결정 축

층은 [../image-brief.md](../image-brief.md) §3을 따른다. 아래는 장르마다 결과를 가르는 축이다. 첫 문장에는 용도와 촬영 방식을 쓴다.

**스튜디오 인물.** 결정 축은 배경지와의 분리, 주광 방향과 그림자 대비, 크롭과 시선, 보정 정도다. "스튜디오"라는 단어만으로 조명이 정해졌다고 보지 않는다.

**일상 셀피.** 먼저 촬영 방식을 하나로 정한다: 팔을 뻗은 전면 카메라, 거울 셀피, 다른 사람이 찍은 폰 스냅(셀피 아님). 전면 카메라면 폰은 프레임 밖에 있고 뻗은 팔·어깨 각도와 가까운 거리의 가장자리 늘어짐이 보인다. 거울 셀피면 반사 안에 폰의 뒷면과 쥔 손이 보이고, 시선은 폰 화면과 거울 속 자신 중 하나로 정한다. 폰이 얼굴을 가리려면 폰을 얼굴 높이로 올리고, 가슴 높이로 들면 얼굴이 드러난다. 플래시는 요청했거나 어두운 장면일 때만 쓰고, 쓰면 광점은 반사 속 폰 위치에 생긴다. 실내 빛은 실제 광원(창, 천장등, 스탠드, 폰 플래시)으로 쓰고 생활감은 요청했거나 손에 쥔 소품 한두 개로 준다. 앱 보정·필터감은 요청됐을 때만 쓴다.

**패션 화보.** 의상이 주인공이다. 첫 줄에 캠페인·매거진·룩북 중 용도를 쓰고 의상 정보를 가장 구체적으로 쓴다. 포즈는 실루엣·원단 움직임·디테일이 읽히는 동작으로 고른다. 로케이션과 빛은 옷의 소재와 색을 드러내는 쪽으로 정한다. 제품 참조의 보존 구조와 인물 보존 축을 구분하되, 위치와 구획은 위 참조 분기를 따른다. 룩북과 화보의 차이는 [photo-results.md](photo-results.md) §룩북 감도.

## 줄이거나 빼는 것

검수한 모음에서 반복된 형태다. 새 문안에 옮기지 않는다.

- 같은 사실을 여러 구획에 반복하는 것: 피부·헤어·팔레트를 `SUBJECT`·`FACE`·`TEXTURE`·`PALETTE`에 나눠 쓰거나, 앞 구획에서 정한 조건(폰이 보이지 않음)을 `CONSTRAINTS`에서 다시 쓰는 것.
- 서로 부딪치는 지시: 참조 없음과 첨부 얼굴 유지, 림라이트 금지와 림라이트, 배경 전체 선명과 얕은 심도, 카메라를 의식하지 않음과 렌즈 응시, 블루아워와 한밤. `low eye-level`처럼 섞인 높이, `soft`와 직광 플래시 동시 지정도 여기에 든다.
- 이유 없는 mm·조리개 수치, 색 지정이 없는데 피부·머리·그림자까지 쓰는 HEX 코드.

## 검수

답변에 출력하지 않는 내부 확인이다.

- 모델 아이덴티티가 있으면 외모 서술이 없는가
- 참조가 없으면 보존 문구가 없는가. 있으면 번호·역할이 있고 참조 외모를 다시 묘사하지 않았는가
- 카메라 위치·광원·반사·손의 접촉이 서로 맞는가

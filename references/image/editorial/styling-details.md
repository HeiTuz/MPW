# 스타일링 세부 어휘

이 파일의 표는 열린 예시다. "이 가운데서 고르라"는 목록이 아니다. 축이 맡는 시각 정보를 보여 주는 예이며, 장면에 맞는 다른 표현을 써도 된다.

- 요청했거나 이 축을 맡겼을 때만 쓴다. 맡기지 않은 축은 비워 둔다.
- 국적·인종·나이·체형에서 끌어내지 않는다. 인물 설정은 [portrait-brief.md](portrait-brief.md) §인물 설정이 정한다.
- 스타일 이름은 화면 결과로 풀어 쓴다([../compiler.md](../compiler.md) §스타일은 화면 결과로). 한 컷에는 결과를 가르는 표현만 고른다.
- 표기는 가장 짧고 정확한 말을 쓴다([../../templates/common.md](../../templates/common.md) §프롬프트 언어 결정).

## 매체 외형

입자·노이즈 어휘는 [../surface-contracts.md](../surface-contracts.md) §3.2.4 판정을 따른다.

| 표현 | 보여 주는 것 | 비고 |
|---|---|---|
| early-2000s compact digital look | 차가운 흰 균형, 하얗게 잘리는 하이라이트, 납작한 암부 | 광원·색 성분은 빛 줄이 받는다 |
| light leak | 프레임 가장자리의 주황·빨강 번짐 띠 | 하이라이트 번짐과 다르다 |
| instant film | 흰 테두리, 낮은 대비, 살짝 틀어진 색 | 제품 브랜드명은 쓰지 않는다 |
| camcorder interlace | 움직이는 가장자리의 빗살 줄, 번진 하이라이트 | 화면 비율은 파라미터 소관이라 여기서 정하지 않는다 |
| purple fringing | 역광 경계의 보라색 테 | |
| fluorescent green-cyan cast | 형광등 아래의 초록·청록 기운 | |
| date stamp | 화면에 렌더되는 글자 | 요청했을 때만 쓰고 정확 카피 규칙([../surface-contracts.md](../surface-contracts.md) §3.2.3)을 따른다 |

## 레그웨어

의상 행의 하위 항목이다. 노출 수위는 [../editorial-fashion.md](../editorial-fashion.md) §노출 수위가 있는 패션 요청이 지배한다. 성적 연출용 레그웨어와 교복·학생을 떠올리게 하는 차림은 이 표에 두지 않는다.

| 표현 | 보여 주는 것 | 비고 |
|---|---|---|
| sheer / semi-opaque / opaque | 원단 농도에 따른 비침 정도 | 숫자 denier는 사용자가 제품 사양으로 줬을 때만 쓴다 |
| back seam | 다리 뒤쪽의 세로 솔기선 | |
| ribbed tights | 세로 골이 만드는 그림자 | |
| matte vs. sheen | 정강이를 따라가는 광택 띠가 있는지 없는지 | |
| slouch socks | 발목에 주름져 쌓인 양말의 볼륨 | |

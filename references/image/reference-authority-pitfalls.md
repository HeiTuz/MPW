# 여러 이미지 참조의 권한 경계

원본 편집과 스타일 참조를 함께 받았을 때 읽는다. 이미지의 역할을 먼저 나누고, 요청된 축만 가져온다. 입력 역할의 판정은 [from-image.md](from-image.md) §1, 제외 입력의 형식은 [surface-contracts.md](surface-contracts.md) §4를 따른다.

## 권한 순서

충돌하는 참조가 있으면 편집 원본과 나머지 참조의 역할을 첫 문장에 명시한다. 실제로 첨부된 이미지에 맞게 슬롯을 연결하고, 포즈나 감도 참조의 대상·의상·소품이 원본을 덮지 않도록 한다.

```text
Edit <primary source>. Keep its subject and outfit. Use <pose reference> for the requested pose and framing only; use <tone reference> for light and color only.
```

## 의상 보존

인물 정체성을 유지하라는 요청은 얼굴만의 보존으로 축소하지 않는다. 원본에 의상이 분명히 보이고 의상 교체가 요청되지 않았다면 의상 종류·색·재질·신발 등 실제 보이는 요소도 남긴다. 반대로 사용자가 의상 변경을 요청했다면 그 축은 잠그지 않는다.

```text
Preserve Image 1 model identity and Image 1 outfit: <garment list>. Use Image 2 only for <layout/props/typography/lighting>.
```

## 소품 전체 교체

탑이나 가구 묶음을 다른 재질로 교체한다면 위쪽 한 부분만 바꾸지 말고 바닥부터 꼭대기까지 새 구조를 서술한다. 인물이 앉는 위치가 중요하면 엉덩이·무릎·손의 지지 관계와 카메라 시점 중 필요한 것만 적는다. 참조에 없는 형태를 정확히 관찰했다고 쓰지 않는다.

## 톤 참조 추출

감도 이미지에서 가져올 빛의 방향, 명암, 색온도, 인쇄 질감 등 보이는 결과만 고른다. 원본의 인물·옷·문구·포즈까지 함께 가져오지 않는다. 이 분리는 사용자 지정 형식을 바꾸거나 별도 단락을 강제하는 이유가 아니다.

## 합성인지 유사 생성인지

원본 피사체를 유지하는 합성이라면 원본 이미지가 편집 베이스다. 비슷한 인상의 새 이미지를 생성하라는 요청이라면 외형의 일반적 특징만 참고하고 원본 얼굴의 동일성 잠금은 요구하지 않는다. 어느 방식인지에 따라 참조의 권한이 달라진다.

## 의상과 소품의 재질 충돌

옷과 무대 소품이 같은 소재여도 서로 다른 대상이다. 재질을 소품에만 적용하려면 입은 옷은 그대로 두고 교체할 구조의 범위를 따로 적는다. 표면이 제공하는 입력 역할과 보존 조건을 [surfaces.md](surfaces.md)에서 확인한다.

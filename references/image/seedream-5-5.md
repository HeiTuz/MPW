# Seedream 5.5 — 생성·편집·레이어 분리

Seedream 5.5를 지정한 요청에 사용한다. 직접 API 설정은 [surface-contracts.md](surface-contracts.md) §4.7에서 실제 호출 표면을 확인할 때만 읽는다. 기존 Seedream 5 Pro와 미지정 이미지의 기본 경로는 [model-routing.md](model-routing.md)를 따른다. 공식 근거와 확인 범위는 [surface-evidence.md](surface-evidence.md) §7에 있다.

## 생성·참조 이미지

- 자연어로 피사체·동작·배경을 먼저 쓰고, 결과를 가르는 조명·재질·구도를 덧붙인다. 여러 참조를 쓰면 실제 첨부 순서대로 `Image 1`, `Image 2`를 부르고 각각 가져올 요소와 보존 범위를 지정한다. 참조가 보여 주는 외형을 반복하지 않는다.
- 글자가 필요한 결과에는 정확한 문자열과 위치·읽는 순서를 적고, 출력에서 특히 작은 글자의 철자·누락·가독성을 확인한다. 사진에는 원하는 빛과 실제 보이는 재질을 적고 불필요한 광택·과노출 같은 결과만 구체적으로 교정한다. 제조사 예시의 품질을 특정 입력의 보장으로 쓰지 않는다.

## 원본 편집과 여러 차례 편집

- 각 편집은 대상·이번 변경과 필요한 보존 요소를 적는다. 여러 차례 이어 편집을 요청받았을 때만 직전 결과를 다음 입력으로 연결하고 이미 승인된 변경을 유지한다.
- 원본별 1회 편집, 상품 리터칭의 원본 우선, 생성 결과 재사용 금지 등 사용자가 정한 조건이 우선한다. 이런 작업은 각 원본을 독립적으로 편집한다. 보존이 중요한 요소는 해당 입력과 출력에서 비교하고, 결과를 대조하기 전 픽셀·색·형상 보존을 확정하지 않는다.

## 투명 자산과 레이어

- 투명 자산은 남길 피사체, 투명해질 영역, 반투명 부분과 경계를 명시한다. 복수 참조에서 요소를 추출할 때는 각 참조의 대상과 합성 결과에서의 배치·겹침 조건을 쓴다. 출력의 실제 알파와 경계를 확인한다.
- 레이어 분리는 원본 한 장에서 어떤 요소를 독립 레이어로 분리하고 무엇을 바탕에 남길지 지정한다. 나중에 글자를 편집할 작업이면 필요한 텍스트 레이어를 지목한다. OCR 결과의 글자·위치·근사 서체는 원본과 대조한다.

# HyperFrames 제작 에이전트에게 주는 프롬프트

이 문서는 HyperFrames HTML 영상 프로젝트를 작성·수정하는 **에이전트 지시**에만 적용한다. Flow·Veo·Seedance 같은 영상 생성 모델에 넣는 클립 문장은 [image/lanes.md](image/lanes.md) §영상 공통 규칙이 맡는다. [HyperFrames Prompt Guide](https://hyperframes.heygen.com/guides/prompting)(2026-09-23 확인)의 작성법을 MPW의 요청 범위·부분 수정·수신 환경 원칙에 맞춰 선택적으로 적용했다. 아래는 프롬프트 설계 지침이며 새 영상 제작이나 품질 실측 결과가 아니다.

## 새 프로젝트와 기존 프로젝트

- **새 프로젝트:** 사용자가 정한 결과, 화면 비율·길이·분위기·핵심 요소를 앞에 둔다. 명시되지 않은 축은 에이전트가 합리적으로 설계하게 둘 수 있다. 가이드의 [cold start](https://hyperframes.heygen.com/guides/prompting)는 이 경우의 예다.
- **기존 자료를 영상화:** 원본 URL·문서·데이터·대본·미디어의 실제 경로와 각 자료의 역할을 알려준다. 자료가 이미 제공됐으면 자리표시자로 치환하거나 출처를 새로 상상하게 하지 않는다. 가이드의 warm start를 기존 프로젝트 재개에 쓸 때는 현재 프로젝트 브리프·소스·선택·검수 상태부터 읽게 하고, 확인된 결정을 다시 인터뷰하지 않는다.
- **부분 수정:** 현재 프로젝트와 이미 맞는 요소를 보존하고 바꿀 구간·축만 지정한다. [공식 반복 수정 안내](https://hyperframes.heygen.com/prompting/iterating)처럼 렌더에서 관찰한 결함을 한 번에 한 축씩 고친다. 새 프로젝트를 처음부터 다시 만들라는 지시로 바꾸지 않는다.

## 필요한 정도만 명세한다

[공식 one-shot 구조](https://hyperframes.heygen.com/prompting/anatomy)의 경로·규격·비트·카피·기법·배제 조건은 **완성 영상을 한 번에 구체적으로 맡길 때** 유용한 선택지다. 모든 요청에 여섯 칸 양식을 강제하지 않는다. 단순한 타이틀 수정은 변경점 하나로 충분하다.

- **시간과 화면:** 여러 비트나 컷을 지정한다면 각 구간의 시작·끝, 화면 요소의 진입·퇴장, 마지막 구간의 의도를 적는다. 영상 길이만 길고 설명된 화면이 짧으면 남은 시간이 정지 화면이 될 수 있다. 동시에 일어나야 하는지, 앞 동작이 끝난 뒤 시작해야 하는지 구분한다. HyperFrames의 타임라인 비트는 편집 위치를 지정하는 말이고, 영상 생성 모델의 프레임 정확도를 보증하는 문법이 아니다.
- **정확한 카피와 소리:** 화면에 써야 할 문구·대사·언어를 원문 그대로 붙인다. “내레이션 없음”과 “모든 오디오 없음”을 구분하고, 제공 음성·음악·효과음의 역할과 파일 경로를 연결한다. 외형·길이·음성 설정이 이미 프로젝트에 있으면 반복 명세하지 않는다.
- **구현 선택:** 필요한 경우에만 특정 그래픽 기법이나 확인된 레지스트리 블록을 명명한다. 색상·위치·이징의 정확도가 중요한 참조 재현에는 관찰한 값만 고정한다. 막연한 분위기 요청에 임의의 hex·초수·블록 이름을 보태지 않는다. [명세 밀도 안내](https://hyperframes.heygen.com/prompting/specification-dial)는 얼마나 결정할지를 고르는 참고 자료다.
- **참조 재현:** 참고 영상이 있으면 길이·구도·카메라 경로·요소별 움직임·겹침·색 중 실제 관찰한 것을 적는다. 비교 렌더에서 어긋난 축을 절대 위치·길이·크기처럼 다시 지정하고 맞는 축은 보존한다([공식 참조 재현 안내](https://hyperframes.heygen.com/prompting/recreating-references)). 텍스트만으로 픽셀 일치를 약속하지 않는다.

## 인계와 판정

수신 환경에 설치된 HyperFrames 스킬·회차 고정 CLI 버전을 사용하도록 연결한다. 슬래시 명령, `init`, 미리보기, 업그레이드를 모든 프롬프트의 필수 머리말로 넣지 않는다. 사용자가 **작성만** 요청했다면 에이전트 지시문만 납품하고, 스킬 설치·렌더를 실행했다고 말하지 않는다. **제작 실행**까지 요청받았다면 프로젝트의 기존 실행·검수 계약에 맞춰 브리프와 실제 렌더를 확인한다. 공식 가이드의 `lint`·`check`·미리보기 제안은 설치 버전과 프로젝트 계약에 맞춰 적용하고, 검사 통과를 미적 완성으로 바꾸어 말하지 않는다.

이 프롬프트는 보통 작업 언어로 쓴다. 정확한 화면 문구·대사·파일명은 그 언어와 철자를 그대로 보존한다. 새 이미지·영상 **생성 모델** 프롬프트의 영어 기본값을 이 에이전트 지시에 자동 적용하지 않는다.

# 리서치·팩트체크 — 축 사전

리서치·팩트체크 템플릿의 섹션 목록은 실행자에게 *"검증하라"*고 시키는 **행동 지시가 아니라, 답에 채워져 나와야 하는 칸 목록**이다. 단계 체크포인트는 기본 off이며, 사용자가 요구했을 때만 "보고 후 진행" 항목으로 넣는다.

## 팩트체크 축

### 판정 가능성 확인 후 등급 선택

증거가 충분할 때 사실 / 대체로 사실 / 절반의 사실 / 대체로 거짓 / 거짓 중 선택한다. 핵심 근거에 접근할 수 없거나 증거가 부족·충돌하면 최종 판정은 **판정 불가**로 두고, 확인된 사실·부족한 근거·판정에 필요한 자료를 쓴다. 증거 부족을 절반의 사실로 바꾸지 않는다.

### 증거 3분류

지지 (Supporting) / 반박 (Contradicting) / 판정불가 (Undeterminable). 증거별 분류와 최종 판정은 구별한다. 개별 증거가 판정불가여도 다른 충분한 증거가 있으면 판정할 수 있고, 전체 근거가 부족하면 최종 판정 불가 경로를 따른다.

### 최신성 탐색 순서

오늘 → 어제–지난주 → 지난 1–3개월 → 지난 1년 → 그 이전. "최신 우선"은 실행 순서로 환원한다.

### 지역 소스 우선 + 교차검증

**1단계** 사안 소재국·분야의 공식 소스 (정부·학회·공식 발표) **→ 2단계** 제3자 독립 기관으로 교차 검증 (국제기구·저널·검증 통계). 2단계라는 점이 핵심이다.

### 의도 추정 보류 + 출처 신뢰도

표절·사기 같은 의도 귀속은 분명한 근거 없으면 "단정 불가"로 기재. 출처 신뢰도 3등급: 높음(공식·학술·검증통계) / 중간(전문미디어·업계보고서) / 낮음(일반미디어·개인의견). 로스터가 아니라 등급 정의만 수용.

### 자료 층위

1차(공식발표·원본) / 2차(분석·학술) / 3차(백과·요약). §templates.md 리서치: "1차 자료 우선"이다. research.md는 왜 그런지까지 채운다.

## 리서치 유형별 축

시장조사: 규모·성장률 / 경쟁 구도 / 고객 니즈 / 기회·위협
경쟁사: 제품·가격 / 시장위치 / 전략·움직임 / 강·약점
학술: 선행연구·문헌 / 방법론 / 발견

## 출력 형식 골격

**팩트체크**: 대상 → 판정(가능하면 5단, 근거 부족이면 판정 불가) → 근거(지지/반박) → 맥락 → 결론 → 출처

**리서치 보고서**: 요약(핵심 3–5개) → 배경 → 핵심 발견(축별) → 분석 → 결론·권고 → 한계 → 출처

예시는 `templates.md` §리서치 참고.

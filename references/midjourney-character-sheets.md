# Midjourney — 캐릭터 시트·전신 레퍼런스

## 적용 조건

사용자가 Midjourney에 인물 레퍼런스를 주고 캐릭터 시트·턴어라운드·전신 고정을 요구할 때 적용한다. 문법·파라미터·슬롯·무드보드 정본은 [midjourney-identity.md](midjourney-identity.md)이고, 이 파일은 **캐릭터 시트의 산문 규칙과 판정 기준**만 갖는다.

**선택한 버전과 실제 참조를 유지한다.** V8 계열의 Edit Model과 V7의 Omni 경로는 [midjourney-identity.md](midjourney-identity.md) §2가 정본이다(2026-09-05 공식 문서 확인). 동일 인물 요구만으로 V7로 바꾸거나 V8에서 동일성 요구를 포기하지 않는다. 참조가 없으면 이미지를 요청한다.

## 파라미터 계약

- 레퍼런스 영향도·네거티브·길이 단위의 값과 subject leakage 처방 순서는 [midjourney-identity.md](midjourney-identity.md) §3·§5·§6·§8이 정본이다. 캐릭터 시트에서 드리프트가 보이면 먼저 레퍼런스 슬롯과 해당 영향도 축을 진단한다.

## 프롬프트 구조

1. 요청한 한 캔버스의 뷰 수·순서·비율을 적는다. 지정이 없을 때만 일반적인 정면·3/4·측면·후면 순서를 제안한다.
2. Edit에는 “첨부 인물의 4뷰 시트를 만든다”처럼 변환을 지시하고, V7 Omni에는 완성 시트를 묘사한다. 참조별 역할과 얼굴·머리·의상 등 실제 보존 조건만 짧게 남긴다.
3. 전신 요청은 “모든 뷰에서 머리부터 발끝까지 보이게” 한 번으로 전달한다. 같은 뜻의 프레이밍 문구를 여러 개 붙이지 않는다.
4. 명시된 신장·체형은 보존하되 임의의 등신 비율·긴 다리·패션 체형으로 바꾸지 않는다. 생성물에서 실제 신장을 정확히 측정했다고 약속하지 않는다.
5. 포즈·의상·조명은 사용자 지정이 우선이다. 비교용 시트라면 일정한 자세·간격·조명만 추가하며, 관찰되지 않은 얼굴 특징이나 국적·나이를 추정하지 않는다.

## 판정

- 얼굴 고정 품질은 얼굴이 보이는 전면·3/4·측면에서만 판단한다. 후면뷰는 얼굴 불가시가 정상이다.
- 한 이미지에 다중 뷰를 넣으면 동일성은 강한 유도이지 절대 보증이 아니다.
- 드리프트가 있으면 먼저 모델·참조 슬롯·인물 역할이 맞는지 확인하고, 승인된 원본과 얼굴·의상·수량을 비교한다. 스타일만 필요한 참조와 동일성을 보존할 참조를 섞지 않는다.
- 한 캔버스 요청은 한 프롬프트로 유지한다. 독립 각도 생성이 필요할 때만 [midjourney-identity.md](midjourney-identity.md) §11을 적용하며, `--repeat`을 통제된 각도 시퀀스로 취급하지 않는다.

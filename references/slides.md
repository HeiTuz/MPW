# 슬라이드·발표 덱 — 조건부 아웃라인 선행 계약

새 다중 컷 덱을 만들거나 기존 덱의 논지·흐름을 재구성할 때는 컷 프롬프트를 쓰기 전에 아웃라인을 확정한다. 이 경우 아웃라인은 모든 컷 산출물의 공통 `requires` 조상이다. 이미 확정된 아웃라인이 있으면 그것을 보존해 사용하고, 단일 슬라이드나 지정 축만 수정하는 요청에는 새 아웃라인을 만들지 않는다.

## 메시지 계층화 3요소

- 핵심 메시지 1문장
- 핵심 메시지를 뒷받침하는 지지 포인트 (청중 관련성 순, 필요한 개수만)
- 발표가 행동·결정을 요구할 때 그 요청을 명시

## 청중 결정 매트릭스

| 질문 | 내용 |
|---|---|
| 주요 청중 | 의사결정권자 / 영향자 / 최종 사용자 |
| 현재 믿는 것 | 청중의 기존 신념·우려 |
| 원하는 결정 | 이 발표 후 취해야 할 행동 |
| 장벽 | 행동을 가로막는 이의제기·비용·위험 |
| 설득 증거 | 장벽을 깨뜨릴 구체적 사실·데이터 |

## 콘텐츠 유형과 시각화 형식

컨텐츠가 무엇인지에 따라 적합한 시각화를 선택한다.

| 콘텐츠 | 시각화 형식 |
|---|---|
| 비교 | 나란한 막대·점 차트 또는 표 |
| 프로세스·순서 | 화살표 흐름도 또는 타임라인 |
| 계층·분해 | 트리맵·썬버스트 또는 아웃라인 표 |
| 시간 변화 | 선 그래프 또는 영역 차트 |
| 통계·합계 | 원형 차트·히스토그램 또는 게이지 |
| 개념·관계 | 다이어그램·마인드맵 또는 네트워크 |

## 아웃라인 표 스키마

아웃라인을 새로 만들거나 재구성할 때는 다음 컬럼으로 잠근다. 기존 아웃라인을 소비하는 작업은 원래 스키마와 확정 조건을 보존한다.

| # | 유형 | 헤드라인 | 핵심 내용 | 시각 요소 | 레이아웃 |
|---|---|---|---|---|---|

타입: 커버 / 컨텍스트 / 콘텐츠 / 마무리 / 클로징 중 하나. 각 슬라이드는 지배적인 메시지와 그에 필요한 보조 내용을 갖는다.

## 발표 흐름 패턴 5종

기본 흐름 하나를 고르고, 내용상 필요할 때만 변형·혼합하며 전체 논리의 일관성을 유지한다.

1. **문제→해결**: 현재 상황 → 문제 정의 → 제안 솔루션
2. **상황→복잡화→해결**: 배경 → 문제 심화 → 해결책
3. **What→Why→How**: 무엇인가 → 왜 중요한가 → 어떻게 실행하는가
4. **과거→현재→미래**: 지금까지 → 현재 상황 → 앞으로의 방향
5. **주장→근거→시사점**: 주요 발견 → 근거 데이터 → 권고사항

## 컷 규칙 3개

- **주요 메시지**: 슬라이드마다 지배적인 메시지 하나를 두고, 필요한 보조 주장과 근거를 함께 배치한다. 독립적인 주장이 여러 개면 슬라이드를 나눈다.
- **자체 완결**: 구두 설명이 없어도 핵심 의도가 전달되도록 텍스트와 그래픽을 구성하되, 발표 맥락을 전제로 한 요소는 명시된 청중·상황에 맞춘다.
- **텍스트 비중**: 데이터·콘텐츠·문맥·마무리·커버/클로징의 정보 밀도는 덱의 목적에 맞춰 조절하고, 고정된 서열을 모든 덱에 강제하지 않는다.

## `feeds` 계약 — 아웃라인에서 컷별 이미지까지

아웃라인 테이블이 다음 단계 입력이 될 때, payload는 다음을 포함한다:

- **형식 명칭과 버전**: 기존 스키마의 명칭과 버전이 정해져 있으면 보존한다. 없는 버전을 새로 만들지 않는다
- **넘어갈 것**: 각 행의 (유형 / 헤드라인 / 핵심 내용 / 시각 요소 / 확정 레이아웃과 보존 조건)
- **안 넘어갈 것**: 폐기한 초안·후보 레이아웃. 미정 레이아웃은 미정으로 표시하고, 다음 단계에서는 미정이거나 재디자인을 요청받은 범위만 정한다
- **보존할 provenance**: 원본 아웃라인의 출처·버전·체크섬 기록 (동일성 검증용)

전달 단계에서 원본 아웃라인과 payload를 대조하고, 수신 단계는 전달된 행과 확정 조건을 확인한 뒤 프롬프트를 생성한다. 전달 계약은 [prompt-graph.md](prompt-graph.md) §5를 따른다.

## 완료 체크리스트

- [ ] 아웃라인이 확정되고 메시지 계층화가 완료되었는가
- [ ] 각 컷이 메시지 1개를 정확히 전달하는가
- [ ] 구두 설명 없이 슬라이드만으로 논지가 따라가는가
- [ ] 컷 간 흐름 패턴이 일관되는가
